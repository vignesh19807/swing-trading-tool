# Defect Register: Swing Trading Intelligence Platform

| ID | Severity | Component | Description | Evidence | Reproduction | Recommended Fix | Status |
|---|---|---|---|---|---|---|---|
| **DEF-001** | **Low** | Backend API (`/api/stocks/{symbol}`) | Route returns HTTP 200 with an empty/INSUFFICIENT dictionary structure instead of standard HTTP 404 when requested symbol is not in the universe | Calling `/api/stocks/INVALID_SYM_XYZ` returns HTTP 200 with `status: INSUFFICIENT` and `warnings: ["Company classification unavailable"]` | `curl http://localhost:8000/api/stocks/INVALID_SYM_XYZ` | Return HTTP 404 with structured detail `{"detail": "Symbol INVALID_SYM_XYZ not found in universe"}` when symbol does not exist in `companies` table. | **Confirmed Defect (Documented)** |
| **DEF-002** | **Low** | Backend API (`/api/stocks/{symbol}/history`) | Unvalidated `timeframe` query parameter falls back silently to default/full history rather than validating against permitted list (`1M`, `3M`, `6M`, `1Y`, `ALL`) | Calling `/api/stocks/TCS/history?timeframe=INVALID_TF` returns HTTP 200 with all 496 candles | `curl http://localhost:8000/api/stocks/TCS/history?timeframe=INVALID_TF` | Add FastAPI `Query` enum/regex validation or raise `HTTPException(status_code=400, detail="Invalid timeframe parameter")`. | **Confirmed Defect (Documented)** |
| **DEF-003** | **Medium** | Database / Historical Data | Production database `quarterly_results` table contains `NULL` for `publication_date` across all 260 rows | `SELECT COUNT(*), COUNT(publication_date) FROM quarterly_results` yields `(260, 0)` | Query SQLite database directly | Ingest verifiable NSE/BSE corporate filing publication timestamps so point-in-time financial filtering does not solely depend on the 45-day statutory fallback lag. | **Accepted Historical Data Limitation** |
| **DEF-004** | **Informational** | Frontend Bundler | Ineffective dynamic import warning in Vite production build: `src/services/api.js` is imported dynamically by `Sidebar.jsx` but statically by other pages | `[INEFFECTIVE_DYNAMIC_IMPORT] src/services/api.js is dynamically imported by src/components/Sidebar.jsx but also statically imported by...` | Run `npm run build` in `frontend/` | Harmonize import style in `Sidebar.jsx` to static `import api from '../services/api.js'` to silence bundler warning. | **Minor Optimization** |
