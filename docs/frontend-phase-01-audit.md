## 8. Environment Variable Approach

**File**: `frontend/.env.example`

```env
VITE_API_BASE_URL=http://localhost:5000   # PLACEHOLDER — confirm backend port
VITE_USE_MOCK_DATA=false
```

**Rules**:
- `.env` — never committed (gitignored)
- `.env.example` — committed (contains only placeholders)
- All `VITE_*` variables are bundled at build time by Vite
- `VITE_API_BASE_URL` is consumed exclusively by `src/services/api.js`
- `VITE_USE_MOCK_DATA` will gate mock data usage in Phase 2

> WARNING: The value `http://localhost:5000` is a placeholder. The actual backend port must be confirmed with the Backend API Engineer before Phase 2 integration begins.

---

## 9. API Service Architecture

All backend communication flows through a single layer:

```
React UI (pages / components)
        |
        v
src/services/api.js          <- single file, single source of truth
        |
        v
Backend REST API             <- HTTP/JSON only, no direct Python access
        |
        v
Backend Data / Logic Services
        |
        v
SQLite Database
```

**Established in Phase 1**:
- `src/services/api.js` — generic `apiFetch()` wrapper
- All future endpoint functions will be added to this file
- No component will call `fetch()` or any HTTP library directly
- Endpoint stubs are documented as comments, ready for Phase 2

## 12. Recommendations for Phase 2

1. **Confirm backend API port** with Backend Engineer — update `VITE_API_BASE_URL` in `.env` and uncomment proxy in `vite.config.js`.

2. **Confirm backend API shape** — review `docs/week11_unified_intelligence_contract.md` and `docs/sector_industry_engine_contract.md` before designing service functions in `api.js`.

3. **Choose a charting library** before building `src/charts/`. Candidates: `recharts` (lightest), `lightweight-charts` (TradingView-style), `chart.js` via `react-chartjs-2`.

4. **Design system first** — implement CSS variables in `src/index.css` using the fintech color palette from the Phase 1 brief before building any UI component.

5. **Router setup** — wire up `react-router-dom` in `src/main.jsx` / `src/App.jsx` with the 5 planned routes before building individual pages.

6. **Theme support** — plan Light/Dark mode via CSS custom properties + `data-theme` attribute before any component styling.

7. **Replace placeholder Vite starter** — `App.jsx`, `App.css`, `index.css` still contain the Vite demo content. These should be the first files replaced in Phase 2.
